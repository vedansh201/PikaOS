# PikaOS
Well PikaOS is an operating system which has a personal pikachu sitting on your desktop. Its a assistant which helps you with your daily tasks such as creating a file/folder, opening apps, checking system information. I have thought of implementing alot of new ideas into this assistant to increase its helpfulness.

## Features
- It has a terminal inside it.
- It has a file manager which can perform tasks such as creating/deleting new folders.
- The icing on the top is the pikachu assistant.

## Note
This project is not complete and is only the first version. I know it has very limited functions right now but I have gotten the base of the project, all i need to do now is add more things and features on top of it.
